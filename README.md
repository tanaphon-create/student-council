# เว็บไซต์คณะกรรมการสภานักเรียน โรงเรียนวังจันทร์วิทยา

ใช้งานฟรี 100% — หน้าเว็บโฮสต์บน **GitHub Pages** ข้อมูลเก็บใน **Google Sheet** ผ่าน **Google Apps Script**

## ฟังก์ชันที่มี
**บัญชีสภา**
- ทุกคนเปิดดูยอดคงเหลือ รายรับ–รายจ่าย กราฟรายเดือน และรายละเอียดทุกรายการได้โดยไม่ต้องเข้าสู่ระบบ
- กรรมการที่ได้รับสิทธิ์เข้าสู่ระบบด้วยชื่อผู้ใช้/รหัสผ่านของตัวเอง แล้ว **บันทึกรายรับ** (ระบุว่าเงินมาจากไหน + รายละเอียด) หรือ **บันทึกรายจ่าย/ถอนเงิน** (ระบุว่าจ่ายให้ใคร/ใช้ทำอะไร + รายละเอียด)
- ชื่อผู้บันทึกถูกแนบกับรายการโดยอัตโนมัติจากบัญชีที่เข้าสู่ระบบ — แก้หรือปลอมชื่อไม่ได้
- ถอนเงินเกินยอดคงเหลือไม่ได้
- ลบรายการไม่ได้ ทำได้แค่ "ยกเลิก" (เฉพาะผู้ดูแลระบบ ต้องระบุเหตุผล) และรายการที่ยกเลิกยังเปิดดูย้อนหลังได้
- ค้นหา กรองตามประเภท/เดือน ดาวน์โหลด CSV (เปิดใน Excel ได้) และพิมพ์รายงาน

**ปฏิทินการปฏิบัติงาน** (อยู่ในหน้าแรก)
- ปฏิทินรายเดือน แยกสีตามประเภท: ประชุม กิจกรรม ปฏิบัติงาน วันสำคัญ อื่น ๆ
- เวรจากระบบเช็คชื่อขึ้นในปฏิทินให้อัตโนมัติ
- กดวันที่เพื่อดูรายละเอียดงาน (เวลา สถานที่ รายละเอียด ผู้บันทึก) และดูรายการ "งานที่กำลังจะมาถึง"
- **เด้งแจ้งเตือน:** เมื่อเปิดหน้าแรกแล้ววันนี้มีงาน (หรือมีงานใน 3 วันข้างหน้า) จะมีหน้าต่างแจ้งเตือนเด้งขึ้นมาทันที วันละครั้งต่อการเปิดเบราว์เซอร์
- ผู้บันทึกงานในปฏิทินคือผู้ที่มีสิทธิ์ "บันทึกปฏิทินงาน" (ประธานนักเรียน ครู) งานหนึ่งกินเวลาหลายวันได้

**เช็คชื่อปฏิบัติงาน**
- ทะเบียนรายชื่อสมาชิกสภาทั้งหมด (เลขประจำตัวนักเรียน ชื่อ ชั้น ตำแหน่ง/ฝ่าย) เพิ่มทีละคนหรือวางรายชื่อจาก Excel ได้ทีเดียวหลายคน เลขประจำตัวห้ามซ้ำ
- ค้นหาสมาชิกด้วยชื่อหรือเลขประจำตัวได้ทั้งในหน้ารายชื่อ หน้าเลือกสมาชิกตอนสร้างงาน และหน้าเช็คชื่อ
- สร้างงาน: ชื่องาน รายละเอียด ช่วงวันที่ วันที่ต้องปฏิบัติ (เลือกได้ จ–อา) เวลาเริ่ม–สิ้นสุด และเลือกสมาชิกที่ปฏิบัติงาน
- เลือกรูปแบบได้ 2 แบบ: **เช็ครายวัน** (เช็คทุกวันที่กำหนด) หรือ **เช็ครวม** (เช็คครั้งเดียวทั้งช่วงงาน)
- หัวหน้าเช็คชื่อได้ 4 สถานะ คือ มา สาย ลา ขาด ใส่หมายเหตุได้ และมีปุ่ม "ตั้งทุกคนเป็นมา" เพื่อเช็คได้เร็ว
- หน้าสรุปผลแสดงยอดรายบุคคล อัตรามาปฏิบัติงาน และตารางเช็คชื่อรายวัน ดาวน์โหลด CSV ได้
- ทุกคนเปิดดูผลได้ แต่เฉพาะผู้ที่มีสิทธิ์ "หัวหน้าเช็คชื่อ" เท่านั้นที่สร้างงานและเช็คชื่อได้ ทุกครั้งที่เช็คจะบันทึกชื่อหัวหน้าผู้เช็คไว้

**โหวต / สำรวจความเห็น**
- ผู้ดูแลระบบเปิดโหวตได้: หัวข้อ รายละเอียด ตัวเลือก (2–30) เลือกได้คนละกี่ตัวเลือก และตั้งเวลาปิดโหวตอัตโนมัติได้
- เลือกได้ทุกโพลว่าใครโหวตได้
  - **ทุกคน** — ใครเข้าเว็บก็โหวตได้ เครื่องละ 1 ครั้ง (เปลี่ยนเครื่อง/เบราว์เซอร์แล้วโหวตซ้ำได้)
  - **สมาชิกสภา** — ยืนยันด้วยเลขประจำตัวนักเรียนในรายชื่อสมาชิก คนละ 1 ครั้ง
  - **รหัสโหวต** — ระบบสร้างรหัสสุ่ม 6 ตัว พิมพ์ตัดแจกคนละใบ รหัสละ 1 ครั้ง เหมาะกับการเลือกตั้ง
- เลือกได้ว่าจะให้เห็นผลทันที หรือซ่อนผลไว้จนปิดโหวต (ผู้ดูแลเห็นผลตลอด)
- บันทึกเป็นร่างก่อนได้ (เช่น เพื่อสร้างและแจกรหัส) แล้วค่อยกดเปิดโหวต ปิด/เปิดใหม่ได้
- ผลโหวตกับรายชื่อผู้ที่โหวตแล้วเก็บแยกชีตกัน จึงไม่ผูกว่าใครเลือกอะไร
- โพลที่กำลังเปิดจะขึ้นแถบ "กำลังเปิดโหวต" ในหน้าแรก

**ผู้ใช้และสิทธิ์** (ผู้ดูแลระบบ) — เพิ่มผู้ใช้ ตั้งรหัสผ่านใหม่ ปิด/เปิดบัญชี และกำหนดสิทธิ์รายคน
| สิทธิ์ | ทำอะไรได้ |
|---|---|
| บันทึกบัญชี | บันทึกรายรับ–รายจ่าย |
| หัวหน้าเช็คชื่อ | จัดการรายชื่อสมาชิก สร้าง/แก้ไขงาน และเช็คชื่อ |
| บันทึกปฏิทินงาน | เพิ่ม/แก้ไข/ลบงานในปฏิทิน (ให้ประธานนักเรียนและครู) |
| ผู้ดูแลระบบ | ทำได้ทุกอย่าง รวมถึงยกเลิกรายการบัญชีและจัดการผู้ใช้ |

ผู้ใช้หนึ่งคนมีได้หลายสิทธิ์ ส่วน "สมาชิก" ในหน้าเช็คชื่อเป็นแค่รายชื่อ ไม่ต้องมีบัญชีเข้าสู่ระบบ

ความปลอดภัย: รหัสผ่านเก็บแบบเข้ารหัส (SHA-256 + salt) ใส่รหัสผิด 5 ครั้งล็อก 10 นาที และเซสชันหมดอายุใน 6 ชั่วโมง

## ลองใช้ก่อนติดตั้ง (โหมดทดลอง)
ถ้า `config.js` ยังไม่มี `API_URL` เว็บจะทำงานในโหมดทดลอง และเก็บข้อมูลไว้ในเบราว์เซอร์นั้นเท่านั้น
ผู้ใช้ทดลอง: `admin` / `admin1234` (ผู้ดูแล), `president` / `demo1234` (ประธานนักเรียน: ปฏิทิน + เช็คชื่อ), `treasurer` / `demo1234` (บันทึกบัญชี) และ `leader` / `demo1234` (หัวหน้าเช็คชื่อ)

## ติดตั้งใช้งานจริง (ประมาณ 10 นาที)

### 1. สร้างฐานข้อมูล Google Sheet
1. เข้า <https://sheets.new> แล้วตั้งชื่อ เช่น `บัญชีสภานักเรียน`
2. เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิมทิ้ง แล้ววางโค้ดทั้งหมดจาก `apps-script/Code.gs`
3. แก้บรรทัด `ADMIN_INITIAL_PASSWORD` เป็นรหัสที่ต้องการ แล้วกด 💾 บันทึก
4. เลือกฟังก์ชัน **setup** ด้านบน แล้วกด **เรียกใช้** และกดอนุญาตสิทธิ์ (ถ้าขึ้นว่า "Google ไม่ได้ยืนยันแอปนี้" ให้กด ขั้นสูง → ไปที่โปรเจกต์)
   ระบบจะสร้างแท็บ `Transactions`, `Users`, `Members`, `Duties`, `Attendance`, `Events`, `Polls`, `Votes`, `Voters`, `VoteCodes` พร้อมผู้ใช้ `admin`

> **ถ้าเคยติดตั้งเวอร์ชันก่อนหน้าแล้ว:** วางโค้ด Code.gs ใหม่ทับ แล้วรัน `setup` อีกครั้ง (ข้อมูลเดิมไม่หาย) จากนั้นทำขั้นตอน "เวอร์ชันใหม่" ตามหมายเหตุในข้อ 2

### 2. เปิดเป็นเว็บแอป
1. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** → ⚙️ เลือกประเภท **เว็บแอป**
2. ดำเนินการในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
3. กดทำให้ใช้งานได้ แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
4. เปิด `config.js` แล้ววาง URL ใน `API_URL: '...'`

> แก้โค้ด Code.gs ภายหลัง ต้องกด **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏️ → เวอร์ชันใหม่** URL จะยังเหมือนเดิม

### 3. เผยแพร่หน้าเว็บฟรีด้วย GitHub Pages
1. สร้าง repository ใหม่แบบ Public บน GitHub เช่น `wcw-student-council`
2. อัปโหลดไฟล์ `index.html`, `style.css`, `app.js`, `duty.js`, `calendar.js`, `vote.js`, `config.js` และโฟลเดอร์ `assets/`
3. **Settings → Pages → Branch: main / root → Save**
4. รอ 1–2 นาที จะได้ลิงก์ เช่น `https://<ชื่อบัญชี>.github.io/wcw-student-council/`

### 4. เริ่มใช้งาน
1. เข้าสู่ระบบด้วย `admin` แล้วกด **เปลี่ยนรหัส** ทันที
2. ไปที่ **ผู้ใช้และสิทธิ์ → เพิ่มสมาชิก** ให้กรรมการที่ต้องบันทึกข้อมูล แล้วติ๊กสิทธิ์ให้ตรงหน้าที่ เช่น เหรัญญิกได้ "บันทึกบัญชี" หัวหน้าฝ่ายได้ "หัวหน้าเช็คชื่อ" ประธานนักเรียนและครูได้ "บันทึกปฏิทินงาน"
3. แจ้งให้แต่ละคนเปลี่ยนรหัสผ่านเองหลังเข้าสู่ระบบครั้งแรก
4. หัวหน้าเช็คชื่อเข้า **เช็คชื่อปฏิบัติงาน → รายชื่อสมาชิก → เพิ่มหลายคน** แล้ววางรายชื่อสมาชิกสภาทั้งหมด จากนั้นกด **+ สร้างงาน**

## หมายเหตุ
- ครูที่ปรึกษาเป็นเจ้าของ Google Sheet จึงเห็นข้อมูลทั้งหมดและสำรองข้อมูลได้เสมอ ไม่ควรแก้แท็บ `Users` ด้วยมือ
- เพิ่มฟังก์ชันอื่นในอนาคต (ข่าว รับฟังความคิดเห็น ทำเนียบกรรมการ) มีการ์ด "เร็ว ๆ นี้" รอไว้ในหน้าแรกแล้ว
